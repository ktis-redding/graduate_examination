### 本サービスの概要（700文字以内）
定例会議の議題に出た残件タスクに対する参加者各自のTODOを明確化、 フォローアップの推進・達成度を可視化するサービスです。
TODOに日付・担当者情報を書き込み、達成/未達成に振り分ける機能を持ちます。
